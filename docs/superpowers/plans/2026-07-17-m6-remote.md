# M6 Remote File Systems Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add typed SFTP, FTPS, and ordinary FTP sessions with explicit identity/risk checks, credential encryption, listing, directory creation, upload/download streams, and deterministic failure handling.

**Architecture:** `remote` owns protocol-neutral models and adapters. UI and Root code never receive protocol clients or shell commands. A `RemoteFileSystem` factory validates a `RemoteProfile`, obtains secrets from `CredentialStore`, and returns a protocol-specific `RemoteSession`; transfer orchestration uses streams and the existing Root/cache repositories at the application boundary.

**Tech Stack:** Kotlin coroutines, Apache Commons Net for FTP/FTPS, JSch for SFTP, Android Keystore AES-GCM, JUnit.
