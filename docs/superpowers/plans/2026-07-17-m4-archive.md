# M4 Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the PRD M4 archive slice: create ZIP files, inspect ZIP/TAR/TAR.GZ/7Z/RAR archives, and safely extract them through typed Root operations with progress, cancellation, atomic publication, and archive-bomb/path-traversal defenses.

**Architecture:** Archive code is split into a format-neutral safety/limit layer, a local engine operating on app-private temporary files, and a Root adapter that streams Root files into private cache and publishes generated/extracted files through the existing one-shot `RootFileTransferRepository`. No UI or ViewModel constructs shell commands. Archive writes are first completed and validated in a private `.isaver-archive-<uuid>.tmp`, then published with the existing no-overwrite Root stream protocol.

**Tech Stack:** Kotlin coroutines/Flow, `java.util.zip`, Apache Commons Compress for TAR/TAR.GZ/7Z, Junrar for read-only RAR, existing typed `RootFileSystem`, `IncomingFileCache`, and `RootFileTransferRepository`.
