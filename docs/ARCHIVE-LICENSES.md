# Archive library notices

iSaver uses Apache Commons Compress `1.27.1` for TAR, TAR.GZ and 7Z inspection/extraction. It is used under the Apache License 2.0; the upstream notice and license remain part of the dependency distribution.

iSaver uses Junrar `7.5.5` only for read-only RAR inspection/extraction. RAR creation is intentionally not exposed. The release checklist must include Junrar's upstream license/notice text and preserve its transitive dependency notices.
