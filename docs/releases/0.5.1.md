# iSaver 0.5.1

## 新增

- 新增非 Root 只读模式，Root 不可用时仍可浏览应用当前有权读取的本地目录和文件。
- “视图”首页新增左上设备入口。
- 新增设备页面，可切换 Root 模式并查看内部存储总量、已用量、可用量和使用率。

## 安全

- 非 Root 模式的数据层统一拒绝所有写操作，不通过 UI 隐藏代替安全门禁。
- 关闭 Root 后立即切换本地只读代理并释放 Root session；重新开启前必须再次通过 Root 检查。
- 非 Root 长按面板隐藏移动、复制、重命名、删除、压缩、编辑和权限修改入口。

## 验证

- 664 个 JVM 测试、Lint、Debug/AndroidTest 构建通过。
- 小米 9 非 Root Android 专项 1/1、Root 流专项 7/7 通过。
- 小米 9 完成 Root -> 非 Root -> Root、模式持久化、内部存储浏览和设备页真实 UI 验收。
- M10 远程能力继续冻结。
