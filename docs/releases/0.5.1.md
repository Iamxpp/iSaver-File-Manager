# iSaver 0.5.1

## 新增

- 新增非 Root 只读模式，Root 不可用时仍可浏览应用当前有权读取的本地目录和文件。
- “视图”首页新增左上设备入口。
- 新增设备页面，可切换 Root 模式并查看内部存储总量、已用量、可用量和使用率。
- 预发布应用与测试命名空间统一迁移为 `com.isaver.filemanager`。

## 性能

- 修复最近项目可用性写入触发 Room Flow 再校验的反馈环，避免持续 Root `stat`、数据库更新和 Compose 重组。
- 可用性未变化时不再写数据库；重新校验期间保留已有行状态，不再闪烁“正在检查”。
- 跳过 `accessMode` 初始值造成的重复全局刷新，仅在模式真正切换时刷新文件视图。

## 安全

- 非 Root 模式的数据层统一拒绝所有写操作，不通过 UI 隐藏代替安全门禁。
- 关闭 Root 后立即切换本地只读代理并释放 Root session；重新开启前必须再次通过 Root 检查。
- 非 Root 长按面板隐藏移动、复制、重命名、删除、压缩、编辑和权限修改入口。

## 验证

- 668 个 JVM 测试、Lint、Debug/AndroidTest/Release 与独立 remote 模块构建通过。
- 小米 9 最近页 UI 3/3、启动 2/2、非 Root 1/1、Root 流 7/7 通过。
- 小米 9 完成 Root -> 非 Root -> Root、模式持久化、内部存储浏览和设备页真实 UI 验收。
- 最近页 10 秒空闲 `/proc` CPU tick 增量为 0，5 秒内无持续渲染帧；旧应用包和旧测试包均已移除。
- M10 远程能力继续冻结。
