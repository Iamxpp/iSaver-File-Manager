# iSaver 0.1.0

Initial local Root file-management release.

## Included

- Root permission gate and structured failure states.
- Recent, locations, and full Root browser tabs.
- WeChat candidates, common locations, and custom Root paths.
- List/grid modes, search, sorting, file information, and folder creation.
- Single-file share/open save workflow with safe no-overwrite publication.
- ZIP creation and safe ZIP, TAR, TAR.GZ, 7Z, and RAR browsing/extraction.
- Android 10/API 29 through Android 15/API 35 compatibility coverage as documented.

## Not Included

- SFTP, FTPS, or FTP user flows.
- Local delete, move, rename, overwrite, or arbitrary file editing.
- SAF, Shizuku, or non-Root operation.

## Installation

This release requires Android 10 or later and a working Root solution. Release APKs must be signed with the publisher's private release key; debug APKs are for development only.
