# iSaver 0.1.3

## 新增

- 新增非 Root 只读模式，可浏览应用当前有权读取的本地目录与文件。
- 新增设备与设置页面，支持切换 Root 模式并查看内部存储使用情况。
- 新增虚拟视图位置、无限层虚拟分组及真实文件和目录引用。
- 新增竖屏和横屏双窗口浏览，并在双窗模式下使用详细列表。
- 完善文件打开、分享、移动、复制、重命名、回收站、压缩与解压、文本编辑、Hex 查看、校验和及文件比较能力。

## 修复与性能

- 应用与测试命名空间统一迁移为 `com.isaver.filemanager`。
- 修复最近项目可用性更新触发 Room Flow 重复校验的问题，避免持续 Root `stat`、数据库写入和 Compose 重组。
- 最近项目重新校验时保留已解析状态，不再反复闪烁“正在检查”。
- 仅在 Root/非 Root 模式真实切换时刷新文件视图。

## 验证范围

- Android 10/API 29 至 Android 15/API 35 构建兼容性。
- JVM 测试、Android Lint、Debug、AndroidTest、Release 与独立 remote 模块构建。
- 小米 9（Android 11/API 30）Root 文件操作、流传输、近期项目稳定性与冷启动验证。

## 暂不包含

- M10 远程 SFTP、FTPS 与 FTP 用户功能继续冻结，不属于本发行版支持范围。

## 安装说明

- 需要 Android 10 或更高版本。
- 未配置私有正式签名之前，GitHub Release 提供 debug 签名的开发构建；签名与已安装版本不一致时需要先卸载旧版本。
