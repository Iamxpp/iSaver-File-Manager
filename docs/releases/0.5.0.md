# iSaver 0.5.0

Local Root file-manager milestone covering M6 through M9.

## Included

- Full local copy, move, rename, create, recoverable replace, trash/restore, archive, extraction, and sharing workflows.
- Application-layer virtual-view folders and real file/directory references.
- Portrait and landscape dual-pane browsing with forced detailed lists in dual-pane mode.
- Text editing, read-only Hex pages, file comparison, four checksum algorithms, and non-recursive permission editing.
- Persistent `NEVER_REPLAY` tasks, `NEEDS_REVIEW` reconciliation, protected-path policy, and no-overwrite publication.
- Xiaomi 9 Root release gates plus API 29, 33, and 35 non-Root compatibility checks.

## Verification

- 648 JVM tests, Lint, four ABI native builds, Debug APK, and AndroidTest APK.
- 23 serial Xiaomi 9 instrumentation groups and visible shared-storage workflow.
- 10,000-entry directory and 512 MiB sparse-file stability checks.
- Root browser cache P95 19.00 ms and 1000-entry first-visible P95 219.19 ms on Xiaomi 9.

See `docs/audits/2026-08-14-m9-local-release-audit.md` for the exact risk matrix and evidence boundaries.

## Not Included

- SFTP, FTPS, FTP, WebDAV, or SMB user flows. `ReleaseFeatures.remoteServers` remains `false`.
- Recursive permission changes, owner/group changes, APK reverse engineering, or a Root terminal.
- SAF, Shizuku, or non-Root file-operation fallback.

Root file operations are fully verified only on the Xiaomi 9 / Android 11 test device. API 29, 33, and 35 Emulator results cover installation and non-Root behavior, not Root filesystem compatibility.
