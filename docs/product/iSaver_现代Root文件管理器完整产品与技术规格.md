## 1. 文档目的

本文定义 iSaver 从“Root 位置浏览与分享另存工具”升级为“完整现代 Root 文件管理器”的产品、交互、架构、安全、测试和发布标准。

本文是新增文件管理能力的主规格。现有 PRD/SDD 继续记录完整产品背景和已实现的分享、Root 浏览、归档等基线；发生冲突时，以本文对 0.2.0 及后续文件管理能力的定义为准，并同步修订 PRD/SDD。

## 2. 产品愿景

iSaver 不再只追求“像 iOS Files”，而是融合两类产品的优势：

- 采用现代、清晰、低噪音的 Files 风格视觉和导航。
- 提供接近 MT 管理器的高效率文件操作、多选、双窗、归档和 Root 能力。
- 对移动、覆盖、删除、权限修改等高风险操作提供比传统 Root 文件管理器更强的校验、预览、事务和恢复能力。
- 保持普通用户可理解，同时让高级用户能够访问完整 Android 文件系统。

产品原则：

1. **先可恢复，再执行写操作**：能进入回收站或生成操作日志时，不直接永久删除。
2. **默认不覆盖**：复制、移动、解压和重命名默认使用无覆盖语义。
3. **路径不是事实**：每次写操作前重新校验 canonical path、设备号、inode、类型和符号链接状态。
4. **操作可观察**：长任务必须有队列、进度、当前文件、速度、剩余量和最终报告。
5. **手机单窗优先，双窗可选**：单手使用不被双窗密度破坏，普通手机竖屏也可主动开启双窗，横屏、折叠屏和平板同样支持。
6. **功能参考，不复制产品**：参考 MT 的高效工作流，不复制其视觉、文案、专有资源或逆向工具实现。
7. **本地闭环优先**：远程协议代码只保留维护；本地 0.2.0 至 0.5.x 全部通过发布门禁后，才启动远程文件开发。

## 3. 参考产品与取舍

MT 官方资料体现的文件管理核心能力包括：双窗口、复制/移动直达另一窗口、多选、书签、过滤、路径跳转、外部或内置打开方式，以及压缩包浏览、创建和解压。

iSaver 的取舍：

| 能力 | iSaver 决策 |
| --- | --- |
| 双窗口 | 支持普通手机竖屏；双窗口始终锁定详细列表显示，单窗可切换图标/详细列表 |
| 单窗移动/复制 | 使用统一“选择目标位置”页面，不要求用户先打开第二窗口 |
| 多选 | 长按进入选择模式，支持全选、反选、同类选择和范围选择 |
| 文件打开 | 优先调用 Android 默认应用；支持“打开方式”重新选择 |
| 压缩包 | 保留内部浏览，扩展创建、解压和冲突策略 |
| Root 操作 | 全部通过 typed operation 和 native helper，禁止 UI 拼 Shell |
| APK 逆向、Dex/Arsc 修改 | 不属于近期文件管理核心范围，后续单独评审 |
| 自动挂载系统分区读写 | 默认不做；高风险系统路径保持只读，后续高级模式单独设计 |

## 4. 当前基线与目标差距

### 4.1 当前已实现基线

- Root 启动门禁与 Root 目录浏览。
- 最近项目、视图、浏览三标签。
- 列表/图标显示、名称/种类/日期/大小排序。
- 虚拟视图位置与新建文件/目录。
- 接收 `ACTION_SEND` / `content ACTION_VIEW` 并安全另存。
- 微信“打开文件所在位置”和“保存到 iSaver”两个入口。
- ZIP、TAR、TAR.GZ、7Z 创建；ZIP、TAR、TAR.GZ、7Z、RAR 浏览和解压。
- Root 文件读取、分享来源缓存和归档发布所需的基础 native helper。
- 普通文件经私有 export cache 和一次性只读 `content://` URI 进入 Android 默认打开流程；压缩包继续进入内置归档浏览器。
- 单个可读普通文件可从长按操作面板经 `ACTION_SEND` 分享到其他应用。
- 单个可读普通文件可进入三标签目标选择器：同一文件系统通过 `renameat2(RENAME_NOREPLACE)` 原子无覆盖移动，跨文件系统通过目标 stage、复制校验、无覆盖发布和按来源 identity 精确删源完成事务移动；同名目标和发布前失败保留来源，发布后删源失败保留两端并明确报告部分成功。

### 4.2 目标核心差距

- 默认打开、文件头 MIME、显式“打开方式”和内置文本/图片只读查看器已完成；APK 专用安装/属性动作仍待高级工具阶段评审。
- 对外分享已支持单/多普通文件和包含目录的私有 ZIP 分享；分享使用私有缓存、一次性只读授权和失败清理。长时 owner 持久化仍是发布门禁增强，不阻塞 M7 本地闭环。
- 移动/复制已支持文件和目录、多选、可恢复替换、递归目录合并、冲突暂停、部分完成报告和脱敏任务 journal；新建文件、单项/批量重命名、删除/回收站及恢复冲突已完成。
- 长按操作面板已承载文件/目录分享、移动、复制、重命名、压缩、删除和属性入口；M7 本地核心闭环已完成，剩余项属于 M8 高级工具或发布门禁。
- 任务中心已持久化状态、项目/已知字节进度、暂停/继续/取消和结果核对；进程死亡后不自动断点重放危险写操作，统一标记为需核对。
- 属性、精确 identity、MD5/SHA-1/SHA-256/SHA-512、虚拟视图位置、跨进程会话路径恢复和单项非递归权限修改已完成。
- 批量重命名、文本只读预览、双窗、文本编辑、Hex、文件对比和权限风险控制已完成；远程适配器代码不属于当前本地开发范围。

## 5. 用户与典型场景

### 5.1 目标用户

- 已 Root，希望访问 `/data`、应用私有目录和共享存储的高级 Android 用户。
- 需要比系统文件管理器更强操作能力，但不希望使用陈旧、拥挤界面的用户。
- 需要频繁打开、分享、归档、移动微信或应用文件的用户。
- 开发者、测试人员和玩机用户。

### 5.2 核心场景

1. 点击 PDF、图片、视频、文档或 APK，使用系统默认应用打开。
2. 长按文件，直接分享到微信、QQ、邮件、网盘或其他应用。
3. 长按一个或多个项目，选择“移动到”，在目标选择器中选目录并执行。
4. 进入 ZIP/7Z/RAR/TAR 包浏览内容，选择目标位置安全解压。
5. 在当前目录新建文件夹、重命名、复制、移动和查看属性。
6. 在 Root 应用目录中批量处理文件，并清楚看到风险等级和结果。
7. 普通手机竖屏、横屏、折叠屏或平板使用双窗口，将一侧选中项目复制/移动到另一侧目录。

## 6. 信息架构

底部导航保持三个一级入口：

- **最近项目**：最近访问、打开、分享、复制、移动、解压和创建的项目。
- **视图**：应用位置、通用位置和虚拟视图位置；回收站是通用位置最后一项，远程服务器入口在本地发布门禁通过前始终隐藏。
- **浏览**：从 `/` 进入完整 Root 文件系统。

新增全局入口：

- 顶栏路径面包屑和路径输入。
- 全局搜索。
- 任务中心。
- 虚拟视图位置。
- 操作历史与失败报告。
- 设置中的显示、操作、安全和高级选项。

## 7. 统一文件操作交互

### 7.1 点击规则

| 项目类型 | 单击行为 |
| --- | --- |
| 目录 | 进入目录 |
| 支持的压缩包 | 默认进入 iSaver 压缩包浏览器 |
| 普通文件 | 使用 Android 默认应用打开 |
| 无默认应用 | 显示系统“打开方式”选择器 |
| 不可读文件 | 显示原因、路径风险和可执行的修复建议 |
| 符号链接 | 显示链接标记；进入前校验目标和循环 |

长按普通文件的“打开方式”可以绕过已保存默认方式，重新选择外部应用或 iSaver 内置查看器。

### 7.2 长按与选择模式

- 长按文件或文件夹进入选择模式，并打开现代底部操作面板。
- 单选面板显示：打开、打开方式、分享、移动到、复制到、重命名、压缩、删除、属性、更多。
- 多选面板显示：分享、移动到、复制到、压缩、删除、属性汇总、更多。
- 目录和文件混选时，只展示所有选中项都支持的动作。
- 支持全选、反选、同类选择和连续范围选择。
- 返回键先退出操作面板，再退出选择模式，最后返回上级目录。

### 7.3 目标选择器

“移动到”“复制到”“解压到”共用 `DestinationPicker`：

- 保留最近项目、视图、浏览三个入口。
- 顶部显示当前目标路径和可写状态。
- 支持在选择器内新建文件夹。
- 底部固定显示“移动到这里/复制到这里/解压到这里”。
- 目标等于来源父目录时禁用移动。
- 目录不能移动或复制到自身及其后代目录。
- 进入目标后立即 Root `stat`；确认执行时再次复核身份。
- 选择器不修改来源选择，取消后返回原目录并保留选择状态。

## 8. 功能需求

### 8.1 FR-OPEN 文件打开与默认方式

当前实现状态：第 1 至 7 项的本地基础闭环已完成：私有导出、可信文件头 MIME、默认应用、系统 chooser、失败处理及文本/图片/归档内置查看均已接入。第 8 项 APK 专用动作尚未实现，不把 APK 高级工具标记为完成。

1. 为 Root 文件生成受控 `content://` 导出 URI，禁止暴露 `file://` 和真实 Root 路径。
2. 根据扩展名、Provider MIME 和文件头生成 MIME；不可信扩展名不能覆盖明确识别的文件头类型。
3. 通过 `ACTION_VIEW` 和 `FLAG_GRANT_READ_URI_PERMISSION` 调用系统默认应用。
4. 系统已有默认处理器时直接打开；没有默认处理器时显示系统选择器。
5. “始终/仅此一次”优先使用 Android 系统默认管理；iSaver 只保存内部查看器偏好，不伪造系统默认。
6. 外部应用不存在、拒绝读取、导出缓存失败时显示可重试错误。
7. 普通文本、图片和归档可选择 iSaver 内置查看器，但不能阻止外部打开。
8. APK 点击默认显示“安装/查看属性/打开方式”，不静默安装。

### 8.2 FR-SHARE 对外分享

1. 长按单个文件选择“分享”，发出 `ACTION_SEND`。
2. 多选仅包含文件时可发出 `ACTION_SEND_MULTIPLE`；混入目录时提示先压缩目录或移除目录。
3. 分享 Intent 必须同时设置 `EXTRA_STREAM`、ClipData、MIME 和临时读取授权。
4. Root 文件先进入应用私有 export cache；外部应用只获得不可猜测的 `content://` URI。
5. 分享缓存按 owner、引用状态和 TTL 清理；不得因 Activity 切后台立即删除仍可能被读取的文件。
6. 默认 TTL 为 30 分钟，可对大文件延长到 2 小时；应用重启清理过期孤儿。
7. 分享前显示准备进度；准备取消必须删除本次缓存。
8. 日志不得记录目标应用、完整路径、URI token 或文件内容。

### 8.3 FR-CREATE 新建

- 新建文件夹：保留现有能力，增加目标身份复核和同名冲突处理。
- 新建空文件：普通浏览模式已实现；默认“未命名.txt”，严格保留名称文本，无覆盖创建并在成功后定位新文件。
- 新建空文件：允许输入完整文件名，默认不覆盖。
- 支持在当前目录和目标选择器内新建。
- 名称拒绝 NUL、`/`、`.`、`..` 和超出文件系统字节限制的值。
- 系统关键路径默认禁用新建，并显示只读原因。

### 8.4 FR-RENAME 重命名

- 单项长按选择“重命名”。
- 同一父目录内使用原子无覆盖 rename。
- 只修改 basename，不接受路径分隔符。
- 目标已存在时提供取消、保留两者和明确替换；默认取消。
- 仅大小写变化在大小写不敏感文件系统上使用安全中间名完成。
- 支持批量重命名预览：查找替换、前后缀、序号、大小写、正则表达式。
- 执行批量重命名前必须验证无重复目标和循环依赖，并展示完整预览。

### 8.5 FR-COPY 复制

- 支持文件、目录、符号链接和多选复制。
- 默认保留文件名、内容、修改时间；权限、owner、SELinux context 仅在用户明确选择且目标支持时保留。
- 目标使用 stage + 无覆盖发布，不直接写最终名称。
- 文件复制完成后验证字节数；高可靠模式可选择 SHA-256 校验。
- 目录复制使用受约束 native walker，不使用拼接的 `cp -r`。
- 冲突策略：逐项询问、全部跳过、全部保留两者、全部替换；“全部”只作用于当前任务。
- 复制任务取消后清理本次 stage，不删除已经完整发布的项目。

当前实现状态（2026-08-13）：长按操作面板支持单个文件或目录，多选工具栏支持可读文件/目录通过三标签目标选择器复制到同一或不同文件系统。批量计划按当前目录顺序逐项调度 typed 原语并显示完成数；首项失败保留选择器，部分完成后失败停止并报告，不自动重放。目录复制使用受限目录 walker，同名目录递归合并，非目录冲突保留两者；普通选择工具栏支持全选、反选和同类选择，覆盖当前完整过滤结果。任务中心记录复制、移动和解压的脱敏生命周期。

### 8.6 FR-MOVE 移动

- 长按单项或多选后选择“移动到”，进入目标选择器。
- 同一文件系统优先执行原子 `renameat2(RENAME_NOREPLACE)`。
- 跨文件系统采用“复制到 stage → 校验 → 发布目标 → 删除来源”的事务流程。
- 删除来源前必须确认目标完整发布且身份未变化。
- 目标发布成功但来源删除失败时，结果为“已复制，未完成移动”，不得自动删除目标或谎报成功。
- 目录移动到自身或后代目录必须在规划阶段拒绝。
- 任务取消发生在目标发布前时清理 stage；发生在发布后、删源前时进入 reconciliation，提示用户核对。
- 操作完成后更新最近项目、当前目录和目标目录缓存。

当前实现状态（2026-08-13）：长按操作面板支持单个文件或目录，多选工具栏支持可读文件/目录通过三标签目标选择器移动。批量计划按当前目录顺序逐项调度 typed 原语并显示完成数；首项失败保留选择器，部分完成后失败停止并报告，不自动重放。目录移动到自身或后代目录会在规划阶段拒绝；同名目录递归合并，非目录冲突保留两者。跨文件系统继续使用校验、发布、精确删源事务，发布后删源失败返回 `MOVE_PARTIAL`，结果不确定不自动重试。任务中心记录移动进度、冲突和终态；应用重启后只需核对，不自动重放。

### 8.7 FR-DELETE 删除与回收站

- 共享存储默认使用 iSaver 回收站，不直接永久删除。
- 回收站按原路径、删除时间、大小和 identity 记录，支持恢复与清空。
- 同文件系统优先原子移动到回收站；跨文件系统回收需要复制校验后再删源，并明确提示成本。
- `/data/user` 等应用私有目录默认显示增强确认，不保证可回收。
- `/system`、`/vendor`、`/product`、`/apex`、`/boot`、`/dev`、`/proc`、`/sys`、`/data/adb` 默认禁止删除。
- 永久删除必须二次确认，并显示项目数、总大小、路径风险和不可恢复说明。
- 递归删除由 typed native walker 执行，逐项 `openat`/`fstatat` 校验，不调用任意 `rm -rf`。
- 删除结果提供成功、部分成功、失败清单和导出报告。

### 8.8 FR-ARCHIVE 压缩与解压

- 保留 ZIP、TAR、TAR.GZ、7Z、RAR 浏览和解压能力。
- 核心版本继续创建 ZIP；后续增加 7Z、TAR、TAR.GZ、TAR.BZ2 创建。
- 单击归档进入内部目录；长按提供“解压到”“在此解压”“打开方式”。
- 解压目标使用统一目标选择器。
- 支持密码归档时，密码只驻留内存，不写日志和持久化存储。
- 保持 Zip Slip、绝对路径、符号链接逃逸、条目数、展开大小和压缩比限制。
- 冲突策略与复制一致；默认不覆盖。
- ZIP 内增量修改、添加、重命名和删除属于后续增强，不进入首个完整文件操作版本。

### 8.9 FR-SEARCH 搜索与过滤

- 当前目录即时过滤不访问子目录。
- 深度搜索必须由用户明确启动，显示扫描范围和取消按钮。
- 支持名称、扩展名、类型、大小、修改日期和正则表达式。
- 默认不读取文件内容；内容搜索作为后续独立功能。
- Root 搜索使用固定并发和速率限制，不能阻塞浏览。
- 搜索结果保留来源路径，支持打开位置、分享、复制和移动。

### 8.10 FR-VIRTUAL-VIEW 虚拟视图位置与历史

- 文件和目录均可添加为真实叶子引用；添加时选择虚拟文件夹并可填写备注。
- 虚拟文件夹可嵌套且只保存应用层分组，不映射真实目录、不保存文件内容。
- 真实引用不能包含子节点；点击目录引用进入普通文件浏览，点击文件引用使用默认打开流程。
- iSaver 移动/重命名项目后按 identity 更新全部匹配引用；外部移动、删除或替换后显示不可用，并允许重试或重新定位。
- 路径历史支持前进、后退和最近访问。后续支持多标签页；配置变更和进程重建不恢复危险 in-flight 写操作。

### 8.11 FR-PROPERTIES 属性与权限

- 属性页显示：名称、完整路径、类型、大小、项目数、修改时间、owner、group、mode、SELinux context、设备号、inode、链接目标和 MIME。
- 目录大小仅在用户点击“计算”后递归统计。
- 支持 MD5、SHA-1、SHA-256、SHA-512 校验；默认推荐 SHA-256。
- 权限修改是高级能力，使用复选框/预设而非八进制自由命令。
- 当前仅支持单项非递归 rwx 修改，禁止递归 `chmod 777`；递归权限修改留待独立设计，实施前必须预览范围并可取消。
- owner/group 修改后续实现，必须从系统解析的 UID/GID 中选择，不允许 UI 拼接命令。

### 8.12 FR-PREVIEW 内置查看与编辑

分阶段提供：

- 图片预览、基础媒体信息、纯文本只读预览。
- 文本编辑器：编码、换行符、查找替换、自动保存恢复、原子保存。
- Hex 查看器：首期只读，后续再评估编辑。
- 文件对比：文本差异和校验和对比。
- APK 信息查看：包名、版本、签名摘要、权限列表；不在核心阶段提供逆向修改。

### 8.13 FR-DUAL-PANE 双窗口

- 普通手机竖屏也支持双窗，由用户主动开启；横屏、折叠屏展开态和平板同样支持。
- 双窗模式强制使用详细列表显示，隐藏图标/网格切换；退出双窗后恢复各窗口的单窗显示偏好。
- 两个窗口各自维护路径、排序、选择和历史。
- “复制到另一窗”“移动到另一窗”是快捷方式，本质仍调用统一 OperationPlanner。
- 支持同步到另一窗、交换窗口和锁定某一窗口。
- 双窗不是单窗目标选择器的替代，两者共享相同安全和冲突策略。

### 8.14 FR-REMOTE 远程文件（延期）

- 本地默认打开、分享、复制、移动、重命名、删除/回收站、搜索、任务中心、双窗和兼容矩阵未全部验收前，不启用入口、不新增协议能力。
- 本地发布门禁通过后，才启用现有 SFTP、FTPS、FTP 适配器，并补齐上传、下载、移动、重命名和删除闭环。
- 新增 WebDAV；SMB 作为独立里程碑评估。
- 远程到本地、远程到远程操作进入同一任务中心。
- 凭据继续由 Android Keystore 保护；SFTP 主机密钥和 FTPS 证书默认严格校验。
- 普通 FTP 始终显示明文风险。

### 8.15 FR-TASKS 任务中心

- 当前将复制、移动、删除、压缩、解压和校验和统一建模为任务；远程传输在远程里程碑启动后接入同一模型。
- 页面显示等待中、运行中、暂停、取消中、需处理、成功、部分成功、失败和结果不确定。
- 显示项目计数、字节进度、当前项目、平均速度、剩余时间和失败数。
- 支持暂停仅限可以安全暂停的操作；原子提交窗口不可暂停或取消。
- 同时运行任务默认 2 个，大量 Root I/O 默认串行，可在设置中调整。
- 操作日志必须脱敏；用户可导出不含 token 和文件内容的结果报告。

## 9. 冲突处理规范

所有复制、移动、重命名、解压和恢复操作使用同一冲突模型：

| 策略 | 行为 |
| --- | --- |
| 取消 | 停止当前冲突项，默认选项 |
| 跳过 | 保留目标，不处理来源 |
| 保留两者 | 使用 `name (1).ext` 等无冲突名称 |
| 替换 | 仅在目标可安全备份或进入回收站时启用 |
| 合并目录 | 逐项处理子项，不等同于覆盖整个目录 |

规则：

- “应用到全部”必须显示当前任务剩余冲突数量。
- 文件和目录类型冲突不能静默合并。
- 替换前再次校验目标 identity；目标变化时重新询问。
- 系统高风险目录禁用“全部替换”。
- 结果不确定时不自动重试、不自动换名、不自动删除来源。

## 10. 界面与体验规格

### 10.1 视觉方向

- 延续浅灰页面、白色内容面、蓝色强调色和系统字体。
- 工作界面强调信息密度和扫描效率，不使用营销式大卡片或装饰性渐变。
- 文件行保持稳定高度；图标、选择框、状态和长文件名不能导致布局跳动。
- 重要危险动作使用语义颜色，但不把整个界面做成红色警告页。
- 支持浅色、深色和跟随系统；禁止平台 Force Dark 二次反色。

### 10.2 浏览页

- 顶栏：返回、可点击路径标题、搜索、显示/排序菜单。
- 内容区：列表或网格；列表默认展示名称、时间、类型/大小和状态。
- 底部：正常态为三标签；选择态切换为操作栏。
- 下拉刷新只刷新当前目录，不重新创建导航栈。
- 长文件名最多三行，完整名称可在属性页复制。

### 10.3 操作面板

- 使用 `ModalBottomSheet`，不是居中小弹窗堆叠大量按钮。
- 首屏显示 4 至 6 个最高频动作，其余放入“更多”。
- 破坏性动作与普通动作分组，删除位于末尾。
- 每个禁用动作提供可读原因。
- 面板标题显示选择数量和简短项目摘要，不显示敏感完整路径。

### 10.4 进度与错误

- 预计少于 500ms 的操作不弹全屏进度。
- 长任务以底部任务条开始，可进入任务中心查看详情。
- 操作完成使用可撤销 Snackbar；只有具备真实撤销能力时才显示“撤销”。
- 部分成功必须显示成功数、失败数和失败清单。
- Root 丢失时暂停新操作，当前原子窗口完成 reconciliation 后回到 Root 门禁。

### 10.5 无障碍

- 所有图标按钮提供 contentDescription。
- 触控目标不小于 48dp。
- 选择状态不能只依赖颜色。
- 支持系统字体放大，长名称和按钮不得重叠。
- TalkBack 按“名称、类型、大小、修改时间、选择状态、可用动作”顺序朗读。

### 11.2 Typed Root 操作

`RootFileSystem` 后续增加窄接口：

```kotlin
suspend fun createFile(parent: RootPath, name: EntryName): OperationResult<DirectoryEntry>
suspend fun rename(source: RootEntryIdentity, target: RootPath): OperationResult<DirectoryEntry>
suspend fun copy(plan: CopyPlan): Flow<FileOperationProgress>
suspend fun move(plan: MovePlan): Flow<FileOperationProgress>
suspend fun trash(plan: TrashPlan): Flow<FileOperationProgress>
suspend fun delete(plan: DeletePlan): Flow<FileOperationProgress>
suspend fun hash(source: RootEntryIdentity, algorithm: HashAlgorithm): Flow<HashProgress>
suspend fun setPermissions(request: PermissionChange): OperationResult<DirectoryEntry>
```

UI、Composable 和 ViewModel 不得传入 shell 命令。所有 native helper 子命令固定、参数化、可测试，不提供通用执行器。

### 11.3 身份模型

每个写操作来源和目标至少记录：

```kotlin
data class RootEntryIdentity(
    val requestedPath: RootPath,
    val canonicalPath: RootPath,
    val device: Long,
    val inode: Long,
    val type: EntryType,
    val sizeBytes: Long?,
    val modifiedAtNanos: Long?,
    val symbolicLink: Boolean,
)
```

Identity 只在有限时间和当前操作阶段有效；进入提交窗口前必须重新读取。

### 11.4 操作规划与执行

```mermaid
flowchart LR
    A[用户选择动作] --> B[OperationPlanner]
    B --> C[来源与目标预检]
    C --> D[冲突预览]
    D --> E[OperationJournal 写入计划]
    E --> F[OperationExecutor]
    F --> G[stage/原子提交]
    G --> H[结果复核]
    H --> I[刷新缓存与最近项目]
```

- Planner 负责拒绝自身/后代目标、关键路径、无权限目标和明显空间不足。
- Executor 只执行冻结后的 typed plan；发现 identity 变化时停止并返回需重新确认。
- Journal 记录脱敏任务 ID、状态、计数和恢复信息，不记录 URI token、文件内容或不必要的完整路径。
- 进程死亡后只恢复可证明安全的等待/暂停任务；处于提交窗口的任务进入“需要核对”，不自动重放。

### 11.5 对外打开与分享桥

首个可靠版本采用“Root 读取到私有 export cache，再由 Provider 授权外部应用”：

1. Root helper 通过现有受约束 `read-file-stdout` 读取已验证文件。
2. 应用写入 `cache/export/<uuid>.tmp`，复核大小后原子改名。
3. `ExternalFileProvider` 只接受 registry 中的随机 token，不接受文件路径。
4. Provider 返回只读 FD，并校验 token、调用模式、cache identity、大小和过期时间。
5. Intent 使用显式临时 URI grant；分享完成后按 TTL 清理。

大文件后续评估 `ProxyFileDescriptorCallback` 随机读，避免完整缓存；在兼容性验证完成前不替换可靠的 cache 方案。

### 11.6 移动事务

同文件系统：

```text
revalidate source + target parent
  -> renameat2(RENAME_NOREPLACE)
  -> verify target identity
  -> record success
```

跨文件系统：

```text
revalidate source + target parent
  -> create target stage
  -> copy and fsync
  -> verify size/hash policy
  -> publish target without overwrite
  -> verify target
  -> delete exact source identity
  -> record success or partial success
```

任何阶段都不能用目标路径存在与否替代 identity 校验。

### 11.7 递归遍历

- 使用目录 FD 和 `openat`/`fstatat(AT_SYMLINK_NOFOLLOW)` 遍历。
- 默认不跟随符号链接；复制链接本身或提示不支持。
- 限制最大深度、项目数和单任务字节数，超过阈值要求确认。
- 检测目录循环、挂载点边界和目标位于来源内部。
- 遍历输出使用版本化二进制或长度前缀协议，不使用换行分隔文件名。

## 12. Root 风险分级

| 等级 | 路径示例 | 默认策略 |
| --- | --- | --- |
| R0 用户共享文件 | `/storage/emulated/0/...` | 正常文件操作，删除优先回收站 |
| R1 应用外部目录 | `/storage/emulated/0/Android/data/...` | 正常操作 + 应用数据提示 |
| R2 应用私有目录 | `/data/user/...`、`/data/data/...` | 增强确认，不默认批量删除 |
| R3 Root 管理与系统配置 | `/data/adb`、`/system`、`/vendor`、`/product` | 默认只读，禁止删除/移动/权限修改 |
| R4 虚拟/设备文件系统 | `/proc`、`/sys`、`/dev`、`/apex`、`/boot` | 只读浏览或完全阻断写操作 |

高级模式不能只是一个总开关。每类高风险能力必须单独启用，并在操作时再次确认。

## 13. 数据与持久化

Room 新增建议表：

- `virtual_view_nodes`：虚拟文件夹/真实引用类型、父节点、显示名、真实路径、identity、可用状态和排序。
- `custom_locations`、`bookmarks`：仅作为 Room 7→8 历史迁移来源保留，不接受当前产品流写入。
- `operation_tasks`：任务类型、状态、总量、完成量、创建/更新时间和恢复策略。
- `operation_items`：仅保存恢复所需的脱敏项目记录；任务结束按 TTL 清理。
- `trash_entries`：原路径、回收位置、大小、删除时间和 identity。
- `open_preferences`：仅保存 iSaver 内置打开方式偏好，不替代 Android 默认应用。

私有路径属于敏感数据：数据库禁止备份，日志和崩溃报告默认脱敏。

## 14. 性能指标

- 目录缓存命中首屏小于 100ms；普通目录冷加载 P95 小于 500ms。
- 长按到操作面板显示小于 100ms。
- 目标选择器打开结构小于 300ms，目录可写性异步刷新。
- 复制/移动进度每 200 至 500ms 更新一次，避免 Compose 高频重组。
- 10,000 项目录滚动保持流畅，列表使用稳定 key 和分页。
- 深度搜索和目录大小计算不得占满全部 Root I/O 并发。
- export cache 和归档 cache 设全局容量上限，空间不足前预检并提示。

## 15. 测试策略

### 15.1 单元测试

- 名称包含空格、中文、单引号、换行、分号、反引号、`$()`、前导 `-` 和 Unicode。
- 路径身份变化、符号链接替换、目标变为文件、跨挂载点和目录循环。
- 同盘移动、跨盘移动、发布后删源失败和结果不确定。
- 复制/解压冲突的跳过、保留两者、替换和应用到全部。
- 目录移动到自身/后代拒绝。
- export token 过期、撤销、重放、错误 caller、cache identity 和大小变化。
- MIME 映射、无默认应用、多个处理器和 ActivityNotFound。
- 回收、恢复、恢复冲突和清空回收站。
- 批量重命名预览重复、循环依赖和大小写文件系统差异。

### 15.2 Native helper 测试

- 同文件系统无覆盖 rename。
- 跨文件系统复制 stage、精确 EOF、额外字节、fsync、发布后按来源 identity 删源和部分成功报告。
- 递归遍历不跟随 symlink，不越过验证目录 FD。
- 删除只作用于计划中的 exact identity。
- 任一超时、kill 或解析失败不留下可见半成品。

### 15.3 Android 集成测试

- 点击文件调用正确 `ACTION_VIEW`、MIME、ClipData 和 grant。
- 长按分享调用 `ACTION_SEND` / `ACTION_SEND_MULTIPLE`。
- 操作面板的单选、多选、禁用原因和返回行为。
- 移动目标选择器的新建目录、自身/后代禁用和目标复核。
- 配置变更、进程重建和新 Intent 到达时任务状态正确。

### 15.4 真机矩阵

- 小米 9 / Android 11：Root 基线、共享存储和 `/data`。
- 小米 17 或当前主力设备：最新 Android 和厂商文件系统差异。
- 至少一台 Android 10 和一台 Android 最新受支持版本。
- 测试文件只放在 `/data/local/tmp/isaver-test` 和专用共享存储目录，不使用真实微信或用户文件。
